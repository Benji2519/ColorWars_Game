# Script storici recuperati da Saved

Copie del 5 novembre 2026. I file Python provengono da `Saved/Codex`; la
configurazione `WeaponIcons/import_weapon_icons.json` proviene da `Saved/CodexWeaponRefs`.

Gli script comprendono ispezioni di rig e animazioni, esportazioni, preparazione
dei materiali e verifiche. Alcuni richiedono il modulo `unreal`, altri Blender.
Alcuni possono salvare o esportare asset; la configurazione delle icone prevede
la sostituzione di asset esistenti. Possono contenere percorsi assoluti o riferimenti
allo stato del progetto dell'epoca.

Sono conservati senza adattamenti o esecuzione. Prima di riutilizzarli, leggerli,
verificarne dipendenze e destinazioni e trasformarli in strumenti documentati.
L'archiviazione non autorizza la loro esecuzione su `Content`.

I report corrispondenti sono in [Docs/Reports/2026-11-05](../../../../Docs/Reports/2026-11-05/README.md).
Provenienza e hash sono nel manifesto della stessa cartella.
