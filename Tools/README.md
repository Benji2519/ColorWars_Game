# Strumenti del progetto

Questa cartella ospita i futuri strumenti condivisi di ColorWars. Non richiede
installazioni aggiuntive finché non viene introdotto uno strumento operativo.

## Convenzioni per nuovi strumenti

- Usare un nome che descriva l'operazione svolta.
- Documentare requisiti, comando di avvio, input, output e possibili modifiche al progetto.
- Calcolare la radice del progetto dalla posizione dello script o da un argomento esplicito; evitare percorsi legati al computer dell'autore.
- Scrivere i dati temporanei in `Saved`; conservare i report finali utili in `Docs/Reports` e i risultati artistici in `ArtSource`.
- Prima di sovrascrivere file, rendere chiaro quali percorsi vengono modificati.
- Tenere qui gli strumenti trasversali; lasciare gli script specifici di BaseSoldier in `ArtSource/Characters/BaseSoldier`.
