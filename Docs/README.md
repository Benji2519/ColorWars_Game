# Documentazione di ColorWars

Le linee guida sono scritte in italiano. I nomi delle directory seguono le
convenzioni del progetto e di Unreal.

| Documento | Uso |
| --- | --- |
| [StrutturaProgetto.md](StrutturaProgetto.md) | Organizzazione della directory principale e regole Git |
| [FlussoDiLavoro.md](FlussoDiLavoro.md) | Istruzioni operative per modifiche e verifiche |
| [VisioneGioco.md](VisioneGioco.md) | Visione, ambito e domande di design |
| [Decisioni.md](Decisioni.md) | Registro delle decisioni approvate |
| [MaterialiSaved.md](MaterialiSaved.md) | Materiali temporanei e materiali da conservare |
| [Reports/2026-11-05](Reports/2026-11-05/README.md) | Copie storiche dei report recuperati da Saved |

## Manutenzione

- Aggiornare la guida pertinente quando cambia una convenzione.
- Registrare in `Decisioni.md` le decisioni che cambiano struttura, strumenti o flusso di lavoro.
- Distinguere sempre una proposta, un dato osservato e una verifica eseguita.
- Usare collegamenti relativi nei documenti e percorsi relativi alla radice nei nuovi strumenti.
- Conservare i report storici senza riscriverne risultati o percorsi: la loro data e provenienza ne definiscono il contesto.

La struttura interna di `Content` non rientra in queste linee guida iniziali.
